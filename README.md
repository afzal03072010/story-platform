# Shadowfang Island — Free Story Book

A React + Vite reading website built from the uploaded manuscript.

## Features

- Username-only entry; no login/account required
- Six chapters from the manuscript
- Character introduction
- Authors/editors credits
- Reading progress stored in localStorage
- Continue reading after refresh
- Dark/light mode
- Reader font-size controls
- Responsive layout for desktop and mobile
- Ready for Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
npm run preview
```

## Deploy

Push this folder to GitHub and import the repository into Vercel. Vercel will detect the Vite app automatically.
